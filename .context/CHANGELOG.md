# Хлопок / Changelog

## 2026-07-27

- Добавлен пайплайн фото каталога: `npm run photos` собирает из `site/photos-src/<slug>/` адаптивные AVIF/WebP/JPEG (ширины 160–2080), кроп 4:3 для превью, blur-заглушку и манифест `src/data/catalog-photos.json`.
- Добавлен QA-скрипт `npm run photos:check`: разрешение, резкость (лапласиан по центральному кропу, калибровка по реальным фото), экспозиция, наличие alt-текстов.
- Карточки товара переведены на `<picture>` с srcset (компонент `CatalogPhoto`), единый кроп 4:3 вместо фиксированной высоты, миниатюры лайтбокса грузят 160px вместо 480px.
- Добавлена Schema.org `ItemList`/`Product` разметка каталога с фото и характеристиками.
- Исправлен счётчик в лайтбоксе: показывал длину легаси-галереи вместо фактического числа фото.
- Оригиналы фото не коммитятся (`photos-src/**` в `.gitignore`), веб-версии и манифест — коммитятся.

## 2026-07-28

- В карточку `Подрамник / мелкое и среднее зерно` загружены 4 фото (лицо, угол, изнутри, макро) с alt-текстами.
- HEIC определяется по магическим байтам, а не расширению: выгрузки с iPhone приходят как `.jpg` с HEIC внутри и раньше не читались (общий модуль `scripts/photo-source.mjs`).
- PNG с альфа-каналом: перед сборкой канал сводится фоном страницы — иначе JPEG-версии получали чёрные области.
- Превью карточки: вписывание (`contain`) вместо кропа (`cover`) — обрезка съедала край изделия. Поля заливаются средним цветом рамки кадра, стык с фоном фото незаметен.
- Детектор смаза: максимум по сетке 3×3 вместо центрального кропа (у товарного кадра центр — ровное полотно, давал ложный «смаз»); альфа сводится до свёртки.
- Порог разрешения разделён: <1200px по длинной стороне — брак, 1200–2080px — предупреждение (мало для лайтбокса). Пустая папка товара — предупреждение, а не ошибка.
- Исправлена blur-заглушка: при картинке из кеша `onLoad` не срабатывал после гидрации и превью навсегда оставалось размытым.
- В карточку `Подрамник / крупное зерно` загружены 3 фото (лицо, угол двунитки, задник) с alt-текстами.
- В карточку `Холст на картоне` загружены 3 фото (лицо, угол, торец 3 мм в руке). Все три позиции каталога переведены на студийные фото, легаси-картинки из `public/media/` в каталоге больше не используются.
- Hero заменён на студийный кадр угла со скобами (`photos-src/hero/`) и переведён на пайплайн: было 505×328 JPEG, растянутый на 66vw (LCP-элемент), стало AVIF 1122px с srcset.
- Пайплайн: если исходник лежит между ступенями ширин (1122 при ступенях 768 и 1200), добавляется его нативная ширина — иначе браузер получал сильно уменьшенный вариант.
- Лайтбокс на тач-экранах: свайп влево/вправо — листать, свайп вниз — закрыть (порог 48px, направление по большей оси). На мобиле добавлена подсказка про жесты.
