# Фото каталога — как готовить

Здесь лежат **оригиналы**. Веб-версии собираются скриптом и попадают в `public/media/catalog/`.

```bash
npm run photos:check   # проверить исходники (разрешение, резкость, экспозиция, alt)
npm run photos         # собрать AVIF/WebP/JPEG + манифест
npm run photos -- --force  # пересобрать всё с нуля
```

## Структура

```
photos-src/
  stretcher-fine/        ← slug из catalogCards в HlopokLandingV2.tsx
    01-front.jpg         ← порядок в карточке = порядок имён
    02-corner.jpg
    03-back.jpg
    alt.json
  stretcher-coarse/
  canvas-board/
```

`alt.json` — подписи для SEO и скринридеров:

```json
{
  "01-front.jpg": "Холст на подрамнике 40x50, мелкое зерно, вид спереди",
  "02-corner.jpg": "Угол подрамника 18x28 мм с натянутым хлопком",
  "03-back.jpg": "Обратная сторона: крепление холста и клинья"
}
```

Slug'и берутся из `catalogCards` в [../src/components/HlopokLandingV2.tsx](../src/components/HlopokLandingV2.tsx).
Пока для slug нет собранных фото, карточка показывает старые картинки из `public/media/`.

## Требования к кадру

| Параметр | Значение | Почему |
| --- | --- | --- |
| Разрешение | от 2080×1560 (лучше 3000+ по длинной стороне) | карточка на retina требует 1200px, лайтбокс — 2080px |
| Формат | JPEG/HEIC/PNG/TIFF, без ретуши-пережатия | пережатие даёт артефакты на зерне холста |
| Ориентация | горизонт, 4:3 или шире | превью кадрируется в 4:3 |
| Фон | однотонный светлый (#f2f0ea…#fbfaf6), без предметов | фон сайта тёплый светлый, серый/синий фон выбивается |
| Свет | мягкий рассеянный, один источник сбоку 30–45° | боковой свет проявляет зерно и рельеф грунта |
| Резкость | по зерну ткани в центре кадра | зерно — главный продающий признак |
| Что не делать | вспышка в лоб, жёлтый свет ламп, тени от фотографа, водяные знаки | |

## Обязательный набор на каждый товар (3–5 кадров)

1. **Лицо** — холст целиком, фронтально, зерно читается.
2. **Угол/торец** — профиль подрамника, видно толщину и качество загиба.
3. **Обратная сторона** — крепление, клинья, перекладины.
4. **Макро зерна** — кадр 10×10 см поверхности (опционально, но сильно продаёт).
5. **Масштаб** — холст в руках или рядом с предметом (опционально).

## Что делает сборка

- применяет EXIF-ориентацию (фото с телефона больше не лежат боком);
- переводит в sRGB, вырезает EXIF/GPS;
- превью: кроп 4:3 с автовыбором смысловой области (`fit: attention`), ширины 480/768/1200;
- лайтбокс: без кропа, ширины 480/768/1200/2080;
- три формата: AVIF (≈−50% к JPEG), WebP, JPEG-фолбэк;
- blur-заглушку 20px в base64 — карточка не мигает пустотой;
- манифест `src/data/catalog-photos.json` с размерами и srcset.
